## Recommendations

1. **Add a test for "test buffer captures debug output"** — straightforward gap. Suggested test in `iostreams_test.go`:

   ```go
   func TestLogger_DebugLandsInTestErrBuffer(t *testing.T) {
       t.Setenv("TWIGGIT_DEBUG", "1")
       ios, _, _, errOut := iostreams.Test()
       ios.Logger.Debug("hello", "key", "value")
       assert.Contains(t, errOut.String(), "hello")
   }
   ```

   And the symmetric silent case without `TWIGGIT_DEBUG` would simultaneously close the two `Partial` rows for scenarios 1 and 2. One test per env-var state is sufficient.

2. **Consider extending `TestLoggerPointer`** to also assert `slog.Default()` matches `sys.Logger` after a manual `slog.SetDefault(sys.Logger)`. The spec scenario "singleton shared across the command factory and iostreams" mentions `slog.Default()` matching the same pointer; current test stops at `NewLogger(os.Stderr)` re-construction.

3. **`TestShellErrors_NoEmoji` orphan** — either add a one-line comment to the test explaining its role as a formatter invariant, or file it under a future `cli-output-no-emoji` requirement. Not a blocker.
